# NFL Statistic Model 🏈

## Overview
The **NFL Statistic Model** is a machine learning project aimed at predicting NFL player and team performance statistics. It uses historical data to answer key questions such as:
- Will a quarterback throw for 250+ yards in a game?
- Will a running back rush for 100+ yards in a game?

This project is designed to assist analysts, bettors, and NFL enthusiasts in making better predictions and decisions.

---

## Features
- **Data Ingestion**: Automated fetching and preprocessing of historical NFL stats.
- **Machine Learning**: Built using a neural network to predict specific performance metrics.
- **Visualization**: Detailed charts and graphs to analyze model performance and predictions.
- **Extendability**: Modular design to allow the inclusion of additional features or data.

---

## Tech Stack
- **Languages**: Python
- **Machine Learning Frameworks**: TensorFlow, Scikit-learn
- **Libraries**: NumPy, Pandas, Matplotlib, Seaborn
- **Environment**: Jupyter Notebook, VSCode
